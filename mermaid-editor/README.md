## 产品简介

**Mermaid 实时编辑器** 是一款基于 Web 的 Mermaid 图表编辑与预览工具，提供类似官方 Mermaid Live Editor 的本地化编辑体验。

### 核心特性

- ✅ **实时预览**：代码编辑即时渲染，所见即所得
- ✅ **语法高亮**：代码编辑器支持 Mermaid 语法
- ✅ **模板库**：内置 6 种常用图表模板
- ✅ **一键复制**：快速复制代码到剪贴板
- ✅ **多格式导出**：支持 PNG/SVG 图片导出
- ✅ **离线可用**：无需联网，本地运行

## 功能详解

### 1. 代码编辑

在左侧编辑器中输入 Mermaid 代码：

```
flowchart TD
    A[开始] --> B[结束]
```

**编辑器特性**：
- 支持 Tab 键缩进（4个空格）
- 自动保存编辑内容
- 实时字符统计
- 错误语法提示

### 2. 实时预览

编辑代码后，右侧预览区会**自动渲染**图表（延迟 500ms）。

**预览特性**：
- 自动适应容器大小
- 支持缩放查看
- 错误时显示友好提示

### 3. 复制代码

点击工具栏 **「📋 复制代码」** 按钮：

1. 当前编辑器中的代码会被复制到剪贴板
2. 页面底部显示「代码已复制到剪贴板！」提示
3. 可直接粘贴到其他地方使用

### 4. 导出图片

#### 导出 SVG（矢量图）

点击 **「💾 导出SVG」** 按钮：

- 适合场景：论文、文档、需要无限放大
- 文件格式：`.svg`
- 特点：矢量无损，文件小

#### 导出 PNG（位图）

点击 **「🖼️ 导出PNG」** 按钮：

- 适合场景：PPT演示、网页展示、社交媒体
- 文件格式：`.png`
- 特点：高清位图，2倍分辨率

## 模板使用

### 打开模板菜单

点击工具栏 **「📋 模板」** 按钮，展开模板列表。

### 内置模板

| 模板名称 | 用途 | 示例场景 |
|---------|------|---------|
| **流程图** | 展示流程、决策分支 | 业务流程、算法流程 |
| **序列图** | 展示对象交互时序 | API调用、系统交互 |
| **类图** | 展示类结构和关系 | UML设计、代码结构 |
| **饼图** | 展示数据占比分布 | 项目时间分配、资源占比 |
| **甘特图** | 展示项目进度计划 | 项目管理、任务排期 |
| **ER图** | 展示实体关系 | 数据库设计、数据模型 |

### 使用模板

1. 点击模板菜单
2. 选择需要的模板类型
3. 编辑器自动填充模板代码
4. 预览区显示渲染结果
5. 根据需要修改代码

## 导出图片

### PNG 导出步骤

1. 确保预览区已正确渲染图表
2. 点击 **「🖼️ 导出PNG」** 按钮
3. 浏览器自动下载 `mermaid-chart.png` 文件
4. 文件保存在浏览器默认下载目录

### SVG 导出步骤

1. 确保预览区已正确渲染图表
2. 点击 **「💾 导出SVG」** 按钮
3. 浏览器自动下载 `mermaid-chart.svg` 文件
4. 可用矢量图软件（如 Illustrator、Inkscape）编辑

### 导出格式对比

| 格式 | 优点 | 缺点 | 推荐场景 |
|------|------|------|---------|
| **PNG** | 兼容性好，直接使用 | 放大后模糊 | PPT、网页、社交媒体 |
| **SVG** | 矢量无损，可编辑 | 部分软件不支持 | 论文、印刷、二次编辑 |

## 常见问题

### Q1: 图表无法渲染，显示错误？

**可能原因**：
- Mermaid 语法错误
- 关键字拼写错误
- 括号/引号不匹配

**解决方法**：
1. 查看错误提示信息
2. 检查语法是否正确
3. 使用模板验证基本结构

### Q2: 导出的图片空白？

**解决方法**：
1. 确保预览区已正确显示图表
2. 等待渲染完成后再导出
3. 尝试刷新页面重新渲染

### Q3: 中文显示乱码？

**解决方法**：
- 本编辑器已配置中文字体支持
- 如仍有问题，尝试使用其他浏览器

### Q4: 如何调整图表大小？

**方法**：
- 图表会自动适应容器大小
- SVG 格式可无限缩放
- PNG 格式已设置 2 倍分辨率

### Q5: 如何自定义样式？

**方法**：
在代码中添加样式配置：

```
%%{init: {'theme': 'dark'}}%%
flowchart TD
    A --> B
```

支持的 theme 值：`default`, `dark`, `forest`, `neutral`

## Mermaid 语法参考

### 流程图 (Flowchart)

```
flowchart TD
    A[圆角矩形] --> B{菱形判断}
    B -->|是| C[矩形]
    B -->|否| D((圆形))
```

**方向关键字**：
- `TD` / `TB`：从上到下
- `BT`：从下到上
- `LR`：从左到右
- `RL`：从右到左

**节点形状**：
- `[矩形]`
- `(圆角矩形)`
- `((圆形))`
- `{菱形}`
- `[[子程序]]`
- `[(数据库)]`

### 序列图 (Sequence Diagram)

```
sequenceDiagram
    Alice->>Bob: 你好
    Bob-->>Alice: 你好！
```

**箭头类型**：
- `->>` 实线箭头
- `-->> 虚线箭头`
- `-) 实线开放箭头`
- `--) 虚线开放箭头`

### 饼图 (Pie Chart)

```
pie title 数据分布
    "类别A" : 40
    "类别B" : 30
    "类别C" : 30
```

### 甘特图 (Gantt Chart)

```
gantt
    title 项目计划
    dateFormat YYYY-MM-DD
    section 阶段A
    任务1 :a1, 2024-01-01, 7d
    任务2 :a2, after a1, 5d
```

### 类图 (Class Diagram)

```
classDiagram
    class Animal {
        +String name
        +makeSound()
    }
    class Dog {
        +bark()
    }
    Animal <|-- Dog
```

### ER图 (Entity Relationship)

```
erDiagram
    USER ||--o{ ORDER : places
    USER {
        int id PK
        string name
    }
    ORDER {
        int id PK
        date created_at
    }
```
